Predicts whether a browsing session will result in a purchase using XGBoost on 12,330 behavioral sessions. Includes funnel analysis, cohort breakdowns, SHAP explainability, and a Streamlit app with live campaign ROI simulation.

---

## Business Problem

E-commerce companies lose revenue when high-intent users browse but don't buy. This project:

1. **Predicts** conversion probability for each session
2. **Identifies** the behavioral signals that matter most (via SHAP)
3. **Quantifies** revenue left on the table from high-intent non-converters
4. **Simulates** ROI of targeted discount campaigns using model predictions

---

## Dataset

| Property | Value |
|---|---|
| Source | [UCI Online Shoppers Purchasing Intention](https://archive.ics.uci.edu/dataset/468/online+shoppers+purchasing+intention+dataset) |
| Size | 12,330 sessions, 18 features |
| Target | `Revenue` — True (converted) / False (did not convert) |
| Class balance | ~15.5% positive (converted) — imbalanced |

---

## Key Results

| Model | CV ROC-AUC | Test ROC-AUC |
|---|---|---|
| Logistic Regression | ~0.88 | ~0.88 |
| **XGBoost** | **~0.92** | **~0.91** |

- **Top predictive signals:** PageValues, ProductRelated_Duration, BounceRates, ExitRates, session_engagement_score
- **High-intent segment:** Top 20% predicted sessions convert at ~3–4x the baseline rate
- **Campaign simulation:** 10% discount to top 20% intent sessions yields ~25%+ projected ROI at 30% lift rate

## Setup & Running

### 1. Install dependencies
```bash
pip install -r requirements.txt
```

### 2. Run notebooks in order
```bash
jupyter notebook
```
Execute in this order:
1. `notebooks/01_eda.ipynb` — generates `data/processed/online_shoppers_clean.csv` and EDA plots
2. `notebooks/02_modeling.ipynb` — trains models, saves `app/model/xgb_model.pkl`
3. `notebooks/03_insights.ipynb` — business insights and campaign simulation

### 3. Launch Streamlit app
```bash
streamlit run app/app.py
```

## Key Analyses

### Exploratory Data Analysis (Notebook 01)
- Class imbalance visualization (~84.5% non-converters)
- Conversion rate by month (November peak — holiday spike)
- Visitor type breakdown (returning vs new visitor gap)
- Traffic source conversion efficiency
- PageValues vs bounce rate analysis
- Correlation heatmap

### Modeling (Notebook 02)
- Feature engineering: session engagement score, product time ratio, bounce-exit interaction
- SMOTE oversampling for class imbalance
- Logistic Regression + XGBoost with cross-validation
- ROC curve & precision-recall comparison
- SHAP feature importance + beeswarm plot
- Decision threshold tuning (F1-optimized)

### Business Insights (Notebook 03)
- High-intent session profile (what does a likely buyer look like?)
- Traffic source quadrant analysis (volume vs conversion efficiency)
- Revenue opportunity sizing from high-intent non-converters
- Campaign simulation: 10% discount to top 20% predicted converters
- ROI sensitivity analysis across lift rates

## SQL Analysis

The `sql/` folder contains BigQuery-compatible queries for:
- **Funnel analysis:** Overall CVR, by traffic type, by month, weekend vs weekday, bounce buckets
- **Cohort analysis:** High-intent segments, device/browser cohorts, returning vs new visitor monthly trends
- **Traffic source deep-dive:** Volume vs efficiency quadrant, underperforming sources
